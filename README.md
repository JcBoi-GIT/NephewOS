# NephewOS

### The Operating System for Nephews

My name is JC. And I want to give my Nephew a computer, however, Windows seems really bloated, bad, and insecure. I also do not want to just straight up give him some basic Linux distro with nothing else. Which is why I am making this.

Why go through so much effort for this? You may ask. I care about my nephew. That's why. It's based off of Mint Cinnamon 22.3. I want to have something safe for my nephew so it's harder for him to get malware, but also that he can have fun with.

It comes preinstalled with some software. It's meant to be mainly for entertainment rather than productivity.

For more info, visit the [NephewOS homepage.](https://jcboi-git.github.io/NephewOS/)
