NephewOS

The Operating System for Nephews

Features

  • Based on Linux Mint Cinnamon 22.3
  • Customized Desktop Style
  • Designed for Simplicity and Entertainment

Requirements

Minimum

  • x86-64 CPU Architecture
  • Intel Core i3 / AMD Ryzen 3 (or equivalent)
  • 4 GB RAM
  • 64 GB Storage
  • Linux-compatible GPU with 3D acceleration

Recommended

  • AMD Ryzen 7 (or equivalent)
  • 8 GB RAM or greater
  • 128 GB NVMe SSD or greater
  • 1 (or more) Nephew
