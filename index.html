NephewOS

The Operating System for Nephews

Features

  • Based on Linux Mint Cinnamon 22.3
  • Customized Desktop Style
  • Designed for Simplicity and Entertainment

Requirements

Minimum

  • x86-64 CPU Architecture
  • Intel Core i3 / AMD Ryzen 3 (or equivalent)
  • 4 GB RAM
  • 64 GB Storage
  • Linux-compatible GPU with 3D acceleration

Recommended

  • AMD Ryzen 7 (or equivalent)
  • 8 GB RAM or greater
  • 128 GB NVMe SSD or greater
  • 1 (or more) Nephew

Preinstalled Software

Entertainment

  • FreeTube (YouTube Client)
  • Shortwave (Internet Radio)
  • Celluloid (Video Player)
  • Rhythmbox (Music Player)

Games

  • OpenArena (Quake-style Multiplayer FPS)
  • SuperTux (Mario-style Side-scrolling Platformer)
  • Airstrike (2D Aerial Combat Game)
  • 2048-Qt (Number Puzzle)
  • LTris (Tetris Clone)

Web

  • Firefox (Web Browser)

Other

  • NephewOS Security System

Security System

NephewOS includes a built-in security system designed to
provide protection against viruses and malware.
It combines ClamAV & its background scanning service,
FreshClam for automatic antivirus definition updates,
and activity monitoring to determine when a scan is appropriate.
The goal is to keep security running quietly in the background
without requiring constant user interaction.
